# HiPrime LED

Marketing landing page for **HiPrime LED**, a Florida-based LED screen and
module repair service.

## Live sites

- [GitHub Pages](https://marcosfurquim.github.io/hiprime-led/)
- [OpenAI Sites](https://hiprime-led.marcosfurquim.chatgpt.site/)

## What the page includes

- responsive service-focused landing page
- direct phone and email conversion paths
- LED repair services and four-step repair process
- FAQ and structured business data for search engines
- accessible navigation, reduced-motion support, and mobile call bar
- original HiPrime service flyer

## Local development

Requires Node.js `>=22.13.0`.

```bash
npm install
npm run dev
```

Open `http://localhost:3000`.

## Validation

```bash
npm test
npm run build:pages
```
